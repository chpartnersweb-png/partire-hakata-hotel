# パルティーレ博多ホテル 実装メモ

## 実装済み

- 表示領域の全幅・全高を使う3枚のヒーロー。外観写真を参照した生成画像をWebP化して使用。
- 約6秒間隔・約1.6秒のクロスフェード、小さなズーム、手動選択、一時停止。コピーは固定。
- 画面外・非表示タブ・ダイアログ表示時の再生停止と、動きを減らす設定への対応。
- 101・102・201・202・301・401号室の写真・料金切替、サムネイル、前後操作、タッチスワイプ、写真拡大。
- 2グループの宿泊料金、追加人数料金、清掃費。
- 通常のチェックイン・アウトと、有料の到着前・出発後サービス。
- 住所、地図、実際の外観、駐車場、エレベーターの案内。
- 電話問い合わせ、メニュー、本文へのスキップ、キーボード操作。
- スマートフォンの固定下部バーはヒーロー通過後に表示。

## 画像

元画像は `src/assets` に保持。客室の141枚をWeb用へ変換し、次の枚数を選んで掲載。

| 客室 | 掲載数 |
| --- | ---: |
| 101 | 10 |
| 102 | 11 |
| 201 | 11 |
| 202 | 12 |
| 301 | 11 |
| 401 | 11 |

`src/data/room-images.json` に使用画像と元のファイル名を記録。画像を作り直す場合は `npm run assets:prepare`。HEICを扱うためFFmpeg、WebP出力にsharpを使用する。ヒーローの生成プロンプトはLP制作計画書に記録済み。

## 検証

- Astroの本番ビルドを実行。
- PC相当の幅1600px、タブレット相当の800px、スマートフォンの390px・320pxでレイアウト寸法を確認。
- 320px幅の地図の余白を修正し、320px・390px・800pxで文書全体に横方向のはみ出しがないことを確認。
- ヒーローの高さが現在の表示領域と一致すること、3枚の切替・手動選択・一時停止を確認。
- 6室すべてで部屋番号・写真・平日料金・週末料金が一致することを確認。
- 写真の拡大、次の写真、Escで閉じる操作、メニュー開閉とスクロール復帰を確認。
- 使用する客室画像・サムネイルの存在を確認。
- ブラウザの画面サイズ変更後に撮影APIが不安定になる場面があったため、その幅ではDOMの寸法・操作状態も使って確認。既定の画面サイズに戻すと撮影可能。

## 未設定

- オンライン予約URLは未提供。問い合わせは電話へ接続。
- 本番URL・canonical・OG画像・サイトマップ・構造化データは後続のSEO変更で実装済み。今回のSEO変更後のビルド・ブラウザ確認・公開反映確認は、ユーザー指定により未実施。詳細は`docs/SEO.md`。
- 平日・週末の曜日区分、税込・税別や宿泊税、有料サービスの端数・同時利用条件は独自に補完していない。
- 自動予約・決済機能、実際の電話発信や予約送信は行っていない。

## 起動環境

この環境では通常のnodeコマンドがNVM設定で起動できなかったため、同梱のNode.js v24.22.1を使用してビルドと開発サーバーを起動した。通常の開発にはpackage.jsonのenginesを満たすNode.jsが必要。
