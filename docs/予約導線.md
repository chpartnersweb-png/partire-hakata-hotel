# ページ全体の予約導線

## 予約先

`src/data/hotel.ts` の `bookingUrls` に登録した6室のAirbnb URLを使用する。共通ボタンから特定の部屋へ勝手に遷移させず、希望する客室を選べる構成。

## 追加・変更した場所

| 場所 | 操作 |
| --- | --- |
| ヘッダーの「空室確認・ご予約」 | 6室を選べる予約パネルを開く |
| メニューの「ご予約・お問い合わせ」 | メニューを閉じ、予約パネルを開く |
| PC画面右側の「予約する」 | 閲覧中の位置から予約パネルを開く |
| スマートフォン下部の「空室確認・ご予約」 | 予約パネルを開く。ヒーロー通過後に表示する従来の条件を維持 |
| 料金表 | 料金グループごとに101・102・401／201・202・301の直接予約リンクを表示 |
| ページ下部の予約案内 | 共通の予約ボタンと、6室それぞれへの直接予約リンクを表示 |
| 客室ギャラリー | 従来どおり、選択中の部屋の予約ページへ進む |

## 予約パネル

- `src/components/BookingPanel.astro` に共通化。
- 各部屋の番号、平日・週末料金、Airbnbへのリンクを表示。
- 料金と予約先は既存の共通データを参照。
- Airbnbは新しいタブで開き、リンクの操作名でもそのことを伝える。
- 閉じるボタン・Esc・パネル外のクリックで閉じる。
- 表示中は背景スクロールとヒーローの自動再生を停止する。
- 閉じると元の操作位置へフォーカスを戻す。メニューから開いた場合はメニューボタンへ戻す。
- JavaScriptが利用できない場合、共通のアンカーリンクはページ下部の予約案内へ進む。そこから直接Airbnbへ進める。
- 電話問い合わせを併設。

ユーザーの指定を引き継ぎ、この変更後のビルド・型チェック・ブラウザ・スクリーンショット・外部リンクの遷移テストは行っていない。本番へのデプロイも行っていない。
